# QueryAI — Premium AI Data Analyst Product Homepage

QueryAI is a polished, production-quality SaaS homepage for an AI-powered data analyst platform. Its core promise: **"Ask your data anything."**

---

## 🚀 Key Features

* **Interactive Hero Studio Demo**: Live interactive query box with dataset switching (`MBA Leads Dataset.csv`, `Q1 Sales`, `SaaS Churn`), typing animation, fast 400ms shimmer loading state, animated bar chart build-up, and key insight cards.
* **Data Transformation Pipeline**: Visual step-by-step breakdown ("From raw rows to useful answers") illustrating how CSV data converts to answers + charts.
* **Interactive Dashboard Showcase**: Full dashboard preview with KPI cards (`Total Leads: 1,950`, `Platforms: 3`), tab switchers, and real-time visualization toggles.
* **Interactive Question Chips**: Clickable sample questions ("Which campaign generated the most leads?", "What changed this month?") that populate the hero studio in real-time.
* **Persona & Feature Grid**: 6 capability cards with realistic micro-UI previews and 3 tailored user persona workflows (Analysts, Business Teams, Students).
* **Interactive "Try QueryAI" Workspace**: Accessible modal drawer allowing visitors to test dataset queries live on the site.
* **Mobile & Desktop Responsiveness**: Tested and optimized for **390px mobile** and **1440px desktop** viewports with zero horizontal scrolling.
* **Honest Product Presentation**: No fake testimonials, customer logos, or inflated statistics.

## 💻 Getting Started

### Prerequisites
* Node.js v18+ 
* npm v9+

### Installation & Local Run

1. Clone or navigate to project directory:
   ```bash
   cd QueryAI
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
